Entry for the [make.fun bounty "Weirdest Job Title: Blind Judge Showdown"](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922): one job title, 60 characters at most, the weirdest we could think of.

The entry:

> Senior Vice President of Apologizing to Geese

A real-sounding corporate title with one gloriously specific twist: a senior
executive whose whole job is saying sorry to geese. 45 characters.

## Run

Python 3, standard library only, no network:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes the title to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is unset), then re-reads the
file and verifies it matches the entry exactly. `entry.txt` in this repo
holds the same title with no trailing newline.
